# Запуск baseline на T4 и локальные архивы

Первым запускайте notebooks/01_baseline_colab.ipynb. Второй ноутбук предназначен
для сравнений собственных сэмплеров после получения baseline.
Используйте свежий diffusion-sampling-colab.zip и новую сессию Colab с GPU T4.

Готовый архив находится по пути
`/Users/maria.ignatova/mipt-hw/lm-in-cv-mipt/dist/diffusion-sampling-colab.zip`.
В ячейке загрузки нажмите «Выбрать файлы» и выберите этот файл на компьютере.
Архив попадёт в `/content/diffusion-sampling-colab.zip`, а проект распакуется
в `/content/diffusion-sampling`.

Для пересборки выполните команды в терминале компьютера.

```bash
cd /Users/maria.ignatova/mipt-hw/lm-in-cv-mipt
python3 scripts/build_colab_bundle.py
```

Сборщик упаковывает pyproject.toml, README.md и папки src, configs, scripts,
tests, notebooks, docs внутрь корневой папки diffusion-sampling.

## Параметры

| Параметр | Значение |
|---|---|
| Модель | google/ddpm-cifar10-32, ревизия 267b167 |
| Сэмплер | Готовый DDIM из Diffusers |
| Изображения | 5000, RGB 32×32 |
| Шаги и NFE | 100 шагов, 100 NFE на изображение |
| eta | 0, детерминированный сэмплинг |
| Batch size | 64 |
| Точность | float32, TF32 отключён |
| Расписание | native leading |
| Clipping | Включён, диапазон оценки x0 [−1,1] |
| Начальные шумы | Сохранённый банк fid, первый seed 50000 |
| Прогрев | Один батч на вызов run_experiment, исключён из времени |
| FID | torch-fidelity 0.3.0, inception-v3-compat, 2048 признаков |
| Выборка для FID | 5000 generated против 50000 CIFAR-10 train |

Управляющие переменные в ноутбуке:

```python
RUN_TAG = 't4_ddim100_baseline_v1'
BATCH_SIZE = 64
DOWNLOAD_EVERY_BATCHES = 16
AUTO_DOWNLOAD = True
```

При нехватке памяти измените batch size на 32 и задайте новый RUN_TAG до нового
запуска. При продолжении используйте прежние параметры, исходники и RUN_TAG.
Результаты сохраняются в `/content/diffusion-sampling/results/`.
Папка Colab временная. Скачанные на компьютер ZIP служат постоянными копиями.

## Порядок выполнения

1. Проверить T4, загрузить ZIP с компьютера и установить пакет.
2. Проверить окружение и тесты. Создать и скачать точные начальные шумы.
3. Получить pilot: 16 изображений, 20 NFE, batch size 8. Скачать его архив.
4. Получить первый батч baseline: 64 изображения при 100 NFE. Скачать новые
   результаты и посмотреть оценку оставшегося времени.
5. Продолжить генерацию. При batch size 64 архивы новых батчей запрашиваются
   на отметках 1024, 2048, 3072, 4096 и 5000 изображений.
6. Вычислить FID. Загрузка CIFAR-10 и весов Inception выполняется при необходимости.
7. Посмотреть preview, при желании записать визуальные наблюдения, скачать полный ZIP.

Время генерации включает денойзинг и шаги сэмплера. Загрузка, прогрев, архивирование,
скачивание и FID в него не включены. Поэтому полное время ноутбука будет больше
оценки по одному измеренному батчу.

## Что должно быть получено

После завершения summary.json должен содержать следующие значения.

```text
generated_images = 5000
generation_complete = true
nfe_per_image = 100
sample_equivalent_model_evaluations = 500000
fid = измеренное конечное число
baseline_metrics_complete = true
```

Также нужны generation_seconds, seconds_per_image, manifest с устройством T4,
версиями и точной ревизией весов, sampling_plan, PNG и preview.
В отчёте указываем измеренный FID и протокол FID-5k/real-50k.
Визуальное описание выполняется человеком по сохранённым изображениям.

## Как скачиваются результаты

files.download инициирует скачивание через браузер на компьютер, обычно в «Загрузки».
Разрешите браузеру несколько скачиваний для Colab. Статус индекса отражает создание
ZIP. Сохранение файла на компьютер проверяется через список загрузок браузера.
Архивы и индекс находятся в `/content/diffusion-sampling/results/exports/RUN_TAG/`
в текущей сессии Colab.
В последней ячейке можно выбрать архив и поставить REPEAT_DOWNLOAD=True.

Сначала скачивается initial_noises_*.zip с точными банками debug и fid и исходниками.
Каждый delta ZIP содержит только новые изображения/батчи плюс актуальные метрики,
настройки, preview и исходники. После прерывания индекс позволяет продолжать
с последнего архивированного диапазона в текущей сессии. Сохраняйте все части
на компьютере до завершения генерации и расчёта FID.

Полный *_full_final_fid_*.zip содержит следующие файлы.

```text
run/config.json
run/manifest.json
run/model_contract.json
run/sampling_plan.json
run/summary.json
run/fid.json
run/preview.png
run/images/*.png
run/batches/*.pt
run/generation.log
run/logs/*.log
initial_noise.pt
source.zip
export_manifest.json
```

Для последующего анализа достаточно финального ZIP. В нём есть все 5000 изображений
и точный шум, поэтому промежуточные части не обязательны при наличии целого финального
архива. Они служат резервной копией до окончания расчёта FID. Для повторной генерации
веса модели и зависимости загружаются отдельно. Контрольные суммы файлов находятся
в export_manifest.json.
